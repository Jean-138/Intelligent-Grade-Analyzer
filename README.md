# Intelligent Grade Analyzer

This project is a simple data analysis tool built with Python and NumPy. It analyzes student grades using basic statistics and a rule-based system to simulate a simple intelligent decision process.

## Features

- Stores student grades using NumPy arrays
- Calculates:
  - Average grade
  - Highest grade
  - Lowest grade
- Simple decision system:
  - Average ≥ 7 → Approved
  - Average < 7 → Reproved

## Technologies

- Python
- NumPy

## Note

This is the first version of the project. It will be improved in future updates with Pandas and Machine Learning features.
